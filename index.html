Escenario activo:

Desafío académico de Métodos Numéricos · Universidad Mayor de San Andrés

Distribución óptima de recursos entre unidades organizacionales con Gradientes Conjugados Precondicionado

Se resuelve el sistema simétrico definido positivo Q x = (r − c)/γ con el método de Suñagua (2020) en tres escenarios organizacionales, contrastándolo con el GC simple y con un método directo.

Síntesis del caso

La gerencia de una organización de servicios digitales debe redistribuir su presupuesto entre 8 unidades interdependientes (software, infraestructura, ciberseguridad, datos, soporte, marketing, I+D y talento). El valor organizacional neto se maximiza resolviendo Q x = b, con Q la matriz de costos de escala e interdependencia. Se estudian tres escenarios (ideal, bajo presión financiera, mal condicionado) y se miden precisión, número de condición y velocidad de convergencia.

2 · Caso de estudio

Contexto financiero y organizacional

Una organización dispone de un presupuesto base repartido entre 8 unidades. Para cada unidad i se mide el retorno esperado ri por unidad presupuestada (valor organizacional) y se descuenta el costo de capital c del financiamiento. El valor organizacional neto de una reasignación x es:

V(x) = (r − c·1)ᵀx − (γ/2)·xᵀQx

El primer término es el valor bruto neto de financiamiento; el segundo, la penalización por rendimientos decrecientes (diagonal de Q) e interdependencia entre unidades (fuera de la diagonal). Como V es cóncava, el óptimo anula el gradiente:

∇V = (r − c·1) − γQx = 0  ⟹  Q x = (r − c·1)/γ

Así A = Q, b = (r − c)/γ y xi es la reasignación a la unidad i como fracción del presupuesto base (negativa = recorte). Con γ = 3 fijo en los tres escenarios.

Q = [sisjρij] es simétrica por construcción (la interdependencia de i con j es la de j con i) y definida positiva porque es una matriz de Gram/covarianza de factores de costo linealmente independientes: xᵀQx > 0 para todo x ≠ 0. Por eso GCP es el método natural.

Justificación y procedencia de los datos

  • Datos didácticos. Los costos de escala (0,14–0,24), acoplamientos (0,45–0,70), retornos (7–11 %) y costo de capital (3 %) son ilustrativos, fijados en órdenes de magnitud verosímiles. No provienen de los registros contables de una organización real.
  • Estructura de acoplamiento. Un acoplamiento base común más un incremento dentro de cada bloque de procesos (Tecnología: software + infraestructura; Seguridad y datos; Atención comercial: soporte + marketing; Innovación y talento) garantiza Q definida positiva.
  • Para datos reales: estimar ri desde el ROI histórico de cada unidad y Q desde la covarianza de sus costos/ingresos trimestrales, y pegarlos en el módulo «Entrada de datos».
  • Escenarios. Los tres comparten unidades, γ y estructura; solo cambian coeficientes de Q y r, c (ver sección 5).

Modelado de procesos y reglas de negocio (aporte de Ingeniería de Sistemas)

Flujo del proceso de planificación
  1. Recopilar retornos esperados ri, costo de capital c y costos de escala/acoplamiento de cada unidad.
  2. Normalizar unidades contables entre sistemas (si no, aparece el escenario «mal condicionado»).
  3. Construir Q y b y validar reglas de negocio (abajo).
  4. Calcular la solución de referencia (método directo) y resolver con GCP.
  5. Auditar errores, condicionamiento y convergencia; decidir la reasignación.
Reglas de negocio y de validación
  • RN1. Q debe ser simétrica: la interdependencia entre dos unidades es recíproca.
  • RN2. Q debe ser definida positiva: el costo de reasignar nunca puede ser nulo o negativo (de lo contrario el óptimo no existe).
  • RN3. Se requieren al menos 4 unidades (n ≥ 4) y datos numéricos finitos.
  • RN4. Σxi indica el flujo de caja interdepartamental neto: si es positiva requiere financiamiento adicional al costo c; si es negativa libera caja para la organización.
  • RN5. Un resultado solo se acepta si el residuo relativo es menor que la tolerancia.
